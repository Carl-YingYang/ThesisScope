# ThesisScope

Suriin ang thesis idea mo: pros, cons, feasibility score, risks, at mga tanong ng panel. Libre, walang account.

1. `npm install`
2. `cp .env.example .env` — i-set ang `ZAI_API_KEY` (server-side lang; may built-in SDK fallback kung walang key)
3. `npm run dev` — buksan ang http://localhost:3000

Next.js App Router, isang page lang. Walang database, walang login, walang cookies, hindi sine-save ang mga input.
